# 💳 Credit Scoring Model using Machine Learning

A Machine Learning project that predicts whether a loan applicant is likely to repay or default using financial and credit history information. Developed as part of the **CodeAlpha Machine Learning Internship**.

---

## 📌 Project Overview

Credit scoring plays a vital role in banking and financial institutions. This project predicts loan default risk by analyzing customer financial records using multiple classification algorithms.

The complete workflow includes preprocessing, feature engineering, model training, evaluation, and prediction.
